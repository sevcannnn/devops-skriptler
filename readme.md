DevOps Skriptlər

 Sevcan İsgəndərova

Bu repozitoriyada aşağıdakı Bash skriptləri yerləşir:
- `fayl_info.sh` — fayllar haqqında məlumat göstərir
- `haqqimda.sh` — müəllif və sistem haqqında məlumat verir
- `salam2.sh` — salamlama skripti
- `serverler.sh` — serverlərin vəziyyətini yoxlayır
- `yedek.sh` — faylların ehtiyat nüsxəsini (backup) yaradır
